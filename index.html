youtube-upload プライバシーポリシー

youtube-upload は、運営者が自分の YouTube チャンネルに動画をアップロードするための個人用ツールです。

  • YouTube API を使い、運営者が許可したチャンネルへの動画・サムネイルのアップロードと、チャンネル名の確認だけを行います。
  • 取得したログイン情報は運営者のパソコンにだけ保存し、第三者に渡したり、ほかの目的に使ったりしません。
  • 運営者以外の利用は想定していません。
  • YouTube の利用には YouTube 利用規約と Google プライバシーポリシーが適用されます。
  • 問い合わせ：Google Cloud の同意画面に登録したサポート用メールアドレス
